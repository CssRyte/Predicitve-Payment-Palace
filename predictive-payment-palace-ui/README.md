# Predictive Payment Palace UI

Static HTML/CSS prototype based on the approved wireframe.

Open `index.html` or `login.html` in a browser.

Pages:
- Login
- Onboarding
- Menu & suppliers
- Prep dashboard
- Reorder dashboard
- History & accuracy
- Data setup
- Account settings

This version uses sample data only. MySQL and Ollama must be connected through the Flask backend, not directly from these HTML files.
